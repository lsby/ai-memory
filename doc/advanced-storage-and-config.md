# 高级存储、并发与配置指南

本文档收录了 `@lsby/ai-memory` 的高级底层机制，包括多租户 Schema 隔离、PGlite 单连接互斥与死锁防护、提交与日志底层结构，以及全量构造配置说明。

---

## 一、存储进阶与并发互斥

### 1. 多租户隔离：一个 PGlite，每个用户一个 Schema

三种存储模式（内存、文件、外部）均支持通过 `schema` 参数进行隔离。默认值为 `public`。在多用户服务端场景下，你可以只维护一个外部 PGlite 句柄，为每个用户分配独立的 schema，数据与遗忘序号互不干扰：

```ts
import { PGlite } from '@electric-sql/pglite'
import { vector } from '@electric-sql/pglite-pgvector'
import { 删除记忆空间, 带记忆的智能体 } from '@lsby/ai-memory'

let pglite = new PGlite('./data/ai-memory', { extensions: { vector } })

function 创建用户实例(用户id: string): 带记忆的智能体 {
  return new 带记忆的智能体({
    存储: { 模式: '外部', pglite, schema: `u_${用户id}` },
    向量模型: { 类型: '无' },
  })
}

let 小明 = 创建用户实例('xiaoming')
let 小红 = 创建用户实例('xiaohong')
await Promise.all([小明.初始化(), 小红.初始化()])

// 注销用户：先销毁该用户的实例，再删除对应 Schema (DROP SCHEMA ... CASCADE)
await 小明.销毁()
await 删除记忆空间(pglite, 'u_xiaoming')
```

- `schema` 名必须是合法的 SQL 标识符（字母、数字、下划线），否则构造时报错。
- `删除记忆空间` 拒绝删除 `public`，因为 `pgvector` 扩展注册在 `public` 中。
- 删除前必须先销毁使用该 schema 的所有实例。

### 2. PGlite 连接互斥机制与死锁防护

PGlite 本质上是单连接的 WebAssembly 数据库。Kysely 自带的 PGlite 驱动默认不提供并发锁，若并发查询跑进未提交的事务，会导致状态错乱。

本库在内部对驱动进行了排队互斥封装：

- 锁按 PGlite 对象进行维护，多个实例共用同一个句柄时统一排队。
- 普通查询执行即释放；事务期间独占连接，直到 `COMMIT` 或 `ROLLBACK`。
- 向量（embedding）计算在事务外提前完成，避免外部网络 IO 阻塞数据库锁。
- 带有 `schema` 时，自动管理 `search_path` 的切换与恢复。

> **死锁警告：禁止在事务回调中同步调用同句柄实例的读写**
>
> 在以下同步回调中，事务正持有连接锁：
>
> - `遗忘豁免`（在清理二级记忆的事务中同步调用）
> - 记忆写入与清理的事件回调（如 `添加记忆`、`批量注入记忆`、`更新记忆` 等触发的流程信息回调）
>
> **在这些回调内部，请仅执行内存计算、日志记录或投递外部队列，绝不要再次发起数据库读写，否则将导致自己等待自己的死锁。**

---

### 3. 共享连接锁：`在互斥锁内执行`

当你在同一个外部 PGlite 句柄上建有自己的业务表（如跨用户的共享知识表），并希望与智能体内部事务安全排队时，可以使用导出的互斥锁：

```ts
import { 在互斥锁内执行 } from '@lsby/ai-memory'

let 数量 = await 在互斥锁内执行(pglite, async (): Promise<number> => {
  let 结果 = await pglite.query<{ n: number }>('SELECT count(*)::int AS n FROM "shared"."知识表"')
  return 结果.rows[0]?.n ?? 0
})
```

## 二、记忆提交树与交互遥测

### 1. 记忆提交（Commit Tree）

每次记忆、关联和动态工具的变更都会产生一笔不可变提交及精确 Diff：

- `父提交id` 将提交组成不可变的提交树，无需维护分支名。
- 切换提交只会改变后续注入的生效状态，不会抹除既有历史。

```ts
let 当前提交id = await 实例.查询当前记忆提交id()
let 提交列表 = await 实例.查询记忆提交()

// 回退到父提交（原分支保留）
await 实例.回退最近记忆提交()

// 切换到指定历史提交
await 实例.切换记忆提交(提交列表[0].id)
```

### 2. 交互事件日志

系统将模型调用、工具执行、记忆召回与提交写入一张追加式事件表，提供完整的调用轨迹追溯：

```ts
let 事件组id = crypto.randomUUID()

await 实例.记录交互日志(
  {
    类型: '自定义',
    开始时间: new Date(),
    内容: { 阶段: '准备资料' },
  },
  事件组id,
)

let 事件流 = await 实例.查询交互日志({ 事件组id })

// 按开始时间过滤，例如汇总某一天：[当天 0 点, 次日 0 点)
let 当天日志 = await 实例.查询交互日志({
  开始时间起: new Date('2026-01-01T00:00:00.000Z'), // 包含 (>=)
  开始时间止: new Date('2026-01-02T00:00:00.000Z'), // 不包含 (<)
})
```

`查询交互日志` 的过滤条件：`事件组id`、`类型`、`开始时间起`（包含）、`开始时间止`（不包含），可以任意组合；结果始终按 `序号` 升序，`偏移` / `数量`（默认 100，最大 1000）在过滤之后生效。两个时间都必须是有效的 `Date`，同时给出时要求 `开始时间起` 早于 `开始时间止`，否则抛错。`开始时间` 上有索引（`交互日志表_开始时间_idx`），日志很多时按时间段查询不用从头翻页。

### 3. 自动压缩遥测与模型请求审计字段

`带记忆的智能体.对话` 开头先确定事件组id（调用方传了 `事件组id` 就用，没传就生成），自动压缩和正式那一轮共用这一个事件组。压缩自己往交互日志记一段（手动 `压缩当前会话` 也一样，入口记为 `手动压缩`）：

| 事件类型       | 内容                                                                                             |
| :------------- | :----------------------------------------------------------------------------------------------- |
| `流程开始`     | `入口: '自动压缩'`、`会话id`、`历史字符数`；`上下文消息id` 是压缩前的会话 HEAD。                 |
| `模型请求审计` | 摘要那次模型调用：耗时、`记录`（`发出字符数`、`返回字符数`、可选的 `用量`）。                    |
| `流程结束`     | `结果: '已压缩'`、`前驱会话id`、`派生会话id`、`摘要字符数`。                                     |
| `流程异常`     | `入口`、`会话id`、`历史字符数`、`原因`（`超时` / `中断` / `其他`）、`错误消息`（最多 1000 字）。 |

压缩失败不会影响正式那一轮：原会话保持不变，正式那一轮照常使用未压缩的历史（除非调用方的 `中断信号` 本身已经到点，那一轮会返回结束原因 `中断`）。

**模型请求审计字段（0.6.0 不兼容变更）**：一个字段只装一种东西。

- `模型请求审计记录.发出字符数` / `返回字符数`：一律是真实字符数，与模型商是否返回 usage 无关。
- `模型请求审计记录.用量?`（`模型用量`：`输入token数`、`缓存命中token数`、`输出token数`，都可选）：模型商返回 usage 时填，只带返回了的字段；一个都没返回就没有这个字段。
- `模型审计汇总.发出字符数` / `返回字符数`：各条记录字符数直接相加，单位一律是字符。
- `模型审计汇总.token用量`（`{ 请求次数, 输入token数, 缓存命中token数, 输出token数 }`）：只累加带 `用量` 的记录，`请求次数` 是带 `用量` 的记录条数，用来看 token 数覆盖了多少请求。

从 0.5.0 升级：以前模型返回 usage 时 `发出字符数` / `返回字符数` 存的是 token 数，现在恒为字符数，token 数改读每条记录的 `用量` 和汇总的 `token用量`。已写入交互日志的旧「模型请求审计」事件不会被改写。

## 三、完整配置项速查

### 1. 实例构造配置

| 配置项         | 类型 / 取值                                                | 影响前缀 | 说明                                                                                                                                                                                                                                                                                                                                                    |
| :------------- | :--------------------------------------------------------- | :------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `系统提示词`   | `string`                                                   |    是    | 基础系统提示词，前缀核心部分。                                                                                                                                                                                                                                                                                                                          |
| `存储`         | `{ 模式: '内存' \| '文件' \| '外部', ... }`                |    否    | PGlite 存储配置，支持自定义路径或传入现有句柄与 schema。                                                                                                                                                                                                                                                                                                |
| `向量模型`     | `{ 类型: '无' \| '本地' \| '在线', ... }`                  |    否    | 向量模型配置。在线模式可指定 `维度` 降低存储开销。                                                                                                                                                                                                                                                                                                      |
| `工具列表`     | `智能体工具类型[]`                                         |    是    | 自定义工具列表。                                                                                                                                                                                                                                                                                                                                        |
| `记忆工具筛选` | `(工具名: 记忆工具名) => boolean`                          |    是    | 按需筛选挂载的 23 个记忆工具，未启用的工具不会进入提示词。                                                                                                                                                                                                                                                                                              |
| `记忆提示词`   | `string \| ((工具名列表: string[]) => string)`             |    是    | 自定义记忆操作指南，支持全替换或在默认提示词上追加。                                                                                                                                                                                                                                                                                                    |
| `模型语言包`   | `模型语言包`                                               |    是    | 模型可见的库内置文案与协议映射；默认中文，可传内置英文包或完整自定义包。                                                                                                                                                                                                                                                                                |
| `禁用深度推演` | `boolean`                                                  |    是    | 是否关闭子智能体推演工具。                                                                                                                                                                                                                                                                                                                              |
| `时区`         | `string` (IANA 时区名)                                     |    否    | 时间注入格式时区（如 `Asia/Shanghai`）。                                                                                                                                                                                                                                                                                                                |
| `额外请求参数` | `Record<string, unknown>`                                  |    否    | 透传给模型商的底层参数（如各模型特有的深度思考开关），自动压缩的摘要请求也会带上。                                                                                                                                                                                                                                                                      |
| `自动压缩`     | `{ 触发字符数, 目标字符数, 超时毫秒?, 失败后冷却字符数? }` |    否    | 历史超过 `触发字符数` 时自动压缩成不超过 `目标字符数` 的派生会话。`超时毫秒` 是压缩自己的时限，与调用方 `中断信号` 先到者生效；压缩超时或失败时保留原会话，正式那一轮照常进行。`失败后冷却字符数`：同一会话上次自动压缩失败后，历史字符数比失败时多出不到这个值就不再尝试（依据从交互日志里的 `流程异常` 记录推出，不另存状态）。四个数都必须是正整数。 |
| `遗忘豁免`     | `(记忆: 二级记忆项类型) => boolean`                        |    否    | 返回 `true` 的记忆免受自然遗忘和末位淘汰清理。                                                                                                                                                                                                                                                                                                          |
| `受保护标签`   | `(标签: string) => boolean`                                |    否    | 防止模型工具意外篡改关键业务标签。                                                                                                                                                                                                                                                                                                                      |

语言包中的每个条目都是函数，包括不需要插值的固定文案。自定义语言可以基于内置包完整覆盖：

```ts
import { 带记忆的智能体, 英文模型语言包, type 模型语言包 } from '@lsby/ai-memory'

let 自定义语言包: 模型语言包 = {
  ...英文模型语言包,
  当前时间: (时间): string => `[NOW: ${时间}]`,
  空回复: (): string => 'No response was produced. Please try again.',
}

let 智能体 = new 带记忆的智能体({ 模型语言包: 自定义语言包, 向量模型: { 类型: '无' } })
```

语言包是实例固定前缀的一部分。需要换语言时应创建新实例和新会话，不要在已有不可变会话中原地切换。

---

### 2. 前缀规则说明

大模型商的前缀缓存（Prefix Caching）要求请求的前半部分字节严格不变：

- **影响前缀的参数**：必须在实例初始化或整个会话中保持固定（如 `系统提示词`、`工具列表`、`记忆工具筛选`、`预期结果Schema`）。若这部分发生变动，库会返回 `结束原因: '前缀已变'`，避免无效请求。
- **不影响前缀的参数**：可在每次调用时动态传入（如 `命令`、`当前时间`、`追加注入消息`、`温度`、`核采样` 等）。库会自动将这些动态内容作为消息按固定顺序追加在回合末尾。

## 四、公共 API、生命周期与错误语义

### 1. 生命周期

- `初始化()` 可显式预热；未显式调用时，其他数据库方法会按需自动初始化。
- `销毁()` 可重复调用。内存模式会关闭实例自己的 PGlite；文件模式会在最后一个共享实例销毁后关闭句柄；外部模式的 PGlite 始终由调用方关闭。
- 销毁后不要复用实例；后续数据库操作会抛出“智能体实例已销毁”错误。
- 文件模式的同一路径由进程锁保护，不支持多个进程同时打开。多实例共享同一路径时，应逐个等待实例销毁完成。
- `遗忘豁免`、`受保护标签` 和事务内流程回调必须快速完成，且不能再次访问同一个 PGlite 句柄，否则会形成自等待。

### 2. 完整运行示例

```ts
import OpenAI from 'openai'
import { z } from 'zod'
import { 带记忆的智能体 } from '@lsby/ai-memory'

let 客户端 = new OpenAI({ apiKey: process.env['OPENAI_API_KEY'] ?? '' })
let 智能体 = new 带记忆的智能体({
  系统提示词: '你是具备长期记忆的助手。',
  存储: { 模式: '文件', 路径: './data/memory' },
  向量模型: { 类型: '无' },
})

try {
  await 智能体.初始化()
  let 结果 = await 智能体.对话({
    命令: '请记住：生产环境数据库端口是 5433。',
    预期结果Schema: z.object({ 回答: z.string() }),
    预期结果描述: '对用户的回复',
    回调: async (): Promise<void> => {},
    openai客户端: 客户端,
    模型名称: 'gpt-4o-mini',
  })
  if (结果.结果 === null) console.error('对话未完成：', 结果.结束原因)
  else console.log(结果.结果.回答)
} finally {
  await 智能体.销毁()
}
```

### 4. 错误与结束语义

- 参数不合法、存储初始化失败、数据库约束失败和调用已销毁实例会直接抛出异常。
- 模型流程中可预期的非成功状态不一定抛异常。此时 `回合结果.结果` 为 `null`，`结束原因` 为 `中断`、`超出最大轮次`、`提取结构化数据失败`、`校验失败次数超出上限` 或 `前缀已变`。
- `查找记忆`、`查询会话` 等查询用 `null` 表示目标不存在；`移除记忆`、`切换记忆提交` 等状态变更用 `false` 表示没有完成目标变更。
- 工具业务失败通常以 `{ 结果: '失败', ... }` 返回；工具实现抛出的异常会形成工具失败事件，并由智能体流程决定是否继续。
- 回调也在主流程中被等待；回调抛错会使对应操作失败，因此日志上报应自行处理可恢复错误。
