# @lsby/ai-memory

基于 PGlite 与 pgvector 的 TypeScript 智能体持久化分层记忆扩展。

```bash
pnpm add @lsby/ai-memory
```

```ts
import { 带记忆的智能体 } from '@lsby/ai-memory'
```

该包依赖轻量基础包 `@lsby/ai-agent`，并继续从主入口导出普通智能体 API。只需要无记忆智能体时，可单独安装
[`@lsby/ai-agent`](https://www.npmjs.com/package/@lsby/ai-agent)。

完整文档请参阅[项目仓库](https://github.com/lsby/ai-memory#readme)。
